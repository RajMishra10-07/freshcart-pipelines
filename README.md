# freshcart-pipelines

Data Engineering assignment "From Git to Gold": version control, ELT on Snowflake, an ML pipeline with Mage, and an event stream with RabbitMQ.

## Layout

- elt/ FreshCart ELT notebook (Part B)
- iris_project/ Mage Iris project (Part C)
- stream/ RabbitMQ dispatcher and driver scripts (Part D)
- tests/ pytest tests run by CI
- .github/workflows/ci.yml GitHub Actions workflow
